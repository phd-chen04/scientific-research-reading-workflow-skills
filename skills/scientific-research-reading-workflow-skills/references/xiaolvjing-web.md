# 小绿鲸网页读取

这是一条实际使用过的网页路线，不是公开 API。页面结构和工具能力可能变化；每次以当前工具文档、实际页面和用户授权为准。

## 会话与登录

- 在可用浏览器工具中查找用户的小绿鲸网页；入口为 `https://www.xljsci.com/editor/`。标签 ID、元素序号、版本参数不能跨会话硬编码。
- 需要登录时显示并保留登录页，让用户自己扫码；隐藏页面或创建成功不等于用户已看见二维码。登录后确认文献/笔记列表实际加载。
- 不把 Cookie、令牌、二维码、账号资料写入阅读档案。不得从客户端缓存移取登录信息。
- 默认使用独立页面，不操作用户桌面鼠标键盘；如果工具只能前台操作，报告限制并等待对应授权。
- 避免在用户同时编辑同一笔记时导航。只读操作也可能改变应用访问时间，不能以此推断阅读或新增笔记。

## 笔记正文

1. 在页面中寻找“我的资源 → 笔记本”。读取实际分页和标题，不按标题去重来源。
2. 点击已有笔记可能跳到过滤后的文献列表并打开侧栏；返回列表后重新观察页码和行，避免遗漏或重复。
3. 等待目标标题和正文实际出现。加载中的空内容、上一条缓存文本都不能记录为新笔记正文。
4. 正文可能在 iframe 内。只从已显示 DOM 或实际框架 URL 取得 `documentId`、`activeNoteId` 等标识，不猜测 ID 或请求未观察到的私有端点。
5. 按段落/列表层级提取，区分正文和工具栏/教程文字。图片、公式、手写内容未取得时标注覆盖限制。
6. 只有标题和空项目符号属于空模板；它不证明用户读过，也不证明该论文没有备注或 PDF 批注。

不点击新建、保存、删除或编辑，也不修改编辑器 DOM。

## 备注与分类

- 文献列表中的长备注可能只在视觉上省略，渲染 DOM 仍有全文；优先读取实际单元格。
- 同一单元格的显示层和宽度测量层可能重复呈现，确认是同一内容后去重。不同论文的相似备注不能合并。
- 内容仍截断时记录 partial，可在已观察到的文献信息面板继续读取；不能根据上下文补写原文。
- 保存实际文件夹显示名与已核实层级。显示名含 `/` 不代表父子目录；小绿鲸分类与 Zotero 集合分别记录。

## 覆盖与增量

来源身份采用 documentId＋noteId，正文按明确的规范化策略计算哈希；只规范换行和已确认的呈现重复，不删除数学符号或有意义的层级。

笔记正文、列表备注和 PDF 批注分别记录覆盖。页面版本/时间未验证可靠时，不能仅凭时间跳过内容。失效登录、不可访问和未读部分保留 pending，继续处理其他来源。
